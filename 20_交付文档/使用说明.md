# 使用说明 · AI 智能膳食顾问（HealthPick）

> 本文档面向评审与使用者，说明系统如何启动、如何使用、能力边界与合规约定。全文不含任何内部工程黑话。

## 一、系统是什么

AI 智能膳食顾问是一个面向「减脂塑形 / 增肌强化 / 慢病调理（控糖）」三类人群的饮食助手。用户输入食材、热量或方案类问题，系统基于《中国居民膳食指南》与本地结构化知识库（素材 A 营养基础、素材 B 三套方案、素材 C 平台服务隔离）返回**带来源标注**的膳食参考，并对疾病类问题强制附加医疗免责。

## 二、两种启动方式

**方式 A：本地直接运行（推荐评审验证）**
1. 安装依赖：`pip install -r backend/requirements.txt`
2. 启动服务：`cd backend && python -m uvicorn app.main:app --host 127.0.0.1 --port 8137`
3. 打开界面：浏览器访问 `http://127.0.0.1:8137/`
4. 接口文档：`http://127.0.0.1:8137/docs`

**方式 B：Docker 一键部署**
1. 在项目根目录执行：`docker compose -f deploy/docker-compose.yml up -d`
2. 访问 `http://localhost:8000`
3. 进阶能力（动态 LLM，规划中）：当前版本为**本地规则引擎（BM25 检索 + 合规层）降级模式**，不依赖外部大模型，所有功能均可完整使用；后续版本可通过配置接入 DeepSeek 等动态 LLM 以增强生成能力。

## 三、怎么用

- **直接提问**：在底部输入框输入，例如「鸡胸肉多少千卡？」「减脂期能吃糙米吗？」「糖尿病患者早餐吃什么？」。
- **快捷按钮**：顶部四个按钮一键获取减脂 / 增肌 / 控糖方案或今日食谱。
- **推荐入口**：点击「推荐·减脂 / 增肌 / 调理」获得对应人群的结构化方案（热量区间、代表食材、推荐理由）。
- **示例气泡**：首屏提供可直接点击的示例问题，降低首问门槛。
- **多轮记忆**：同一浏览器会话内，历史对话会被记住并持久化，刷新页面不丢失（会话 ID 存于浏览器本地存储）。
- **来源可见**：每条回答下方标注知识块来源（如 `A · 第一章营养素基础认知 · 1.1 三大宏量营养素`），确保可溯源、零编造。
- **模型标识**：右下角徽章始终显示「本地规则模式」（BM25 检索 + 合规层，不依赖外部大模型）；后续接入动态 LLM 后将更新为对应标识。

## 四、能力边界与合规约定（重要）

1. **医疗免责**：凡涉及疾病、症状、用药的问题，系统**强制附加**免责声明「本建议仅供参考，不构成医疗建议，请咨询专业医师或注册营养师」；若问题含用药咨询（如「吃什么药」），系统**拒绝提供用药建议**，仅给膳食参考。
2. **禁忌拦截**：对话中声明过敏/禁忌（如「我对海鲜过敏」）或选择特殊人群后，推荐与回答会**自动排除对应食材**并明示。
3. **平台信息隔离**：营养问答绝不混入平台价格、会员、企业方案等素材 C 内容；仅在明确问到平台服务时才检索素材 C。
4. **非诊断工具**：本系统提供膳食参考，不替代专业医疗诊断与治疗方案。
5. **零真实密钥**：代码中不含任何真实 API Key，密钥仅通过环境变量注入，未提交进版本库。

## 五、常见问题

- **为什么显示「本地规则模式」？** 当前版本即运行于本地规则引擎（BM25 检索 + 合规层），不依赖外部大模型，功能完整，所有回答由检索原文组织并标注来源。
- **回答很长/像教材？** 当前为检索原文 grounding，所有内容逐字来自素材，可溯源；后续接入动态 LLM 后可摘要为更口语的回答。
- **数据存哪里？** 默认本地 SQLite（WAL 模式），无需外部数据库；会话与历史存于本地，不上云。
