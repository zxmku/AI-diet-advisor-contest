# 本地部署手册 · AI 智能膳食顾问（HealthPick）· v1.20

> 本手册仅用于**本地运行**（考官/用户拉取源码后自行启动）。
> 在线体验请直接用 README 顶部的演示链接，无需本地部署。

## 一、环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows（推荐） / macOS / Linux（Docker 方式） |
| Python | **3.10 / 3.11 / 3.12**（离线依赖包 `deploy/wheels/` 仅内置这三版；3.13 等暂不支持） |
| 网络 | 启动与核心问答**无需联网**（依赖已随仓库打包） |

## 二、方式 A：一键启动（Windows，推荐）

1. 安装 Python 3.10/3.11/3.12（官网 https://www.python.org/downloads ，安装时勾选 **Add to PATH**）。
2. 双击 **`deploy/一键启动.bat`**：
   - 自动查找本机 Python 3.10-3.12 → 用仓库自带离线依赖包安装（不访问外网）→ 启动服务 → 浏览器自动打开。
3. 浏览器访问 **http://127.0.0.1:8137/**，即可对话。

**开启完整 AI 模式（推荐）**：用记事本打开 `deploy/.env`，填入：

```
DEEPSEEK_API_KEY=你的密钥
```

保存后重新双击 `deploy/一键启动.bat` 即生效。

> 未配置密钥也能用全部核心功能（本地规则模式：知识库检索 + 合规层 + 一餐生成，仅无 AI 润色）。

## 三、方式 B：命令行启动（Windows / macOS / Linux）

```bash
cd backend
pip install --no-index --find-links ../deploy/wheels -r requirements.txt   # 离线安装自带依赖
python -m uvicorn app.main:app --host 127.0.0.1 --port 8137
# 浏览器打开 http://127.0.0.1:8137/
```

配置密钥：在 `backend/.env` 或 `deploy/.env`（二选一）写入 `DEEPSEEK_API_KEY=你的密钥`，系统自动识别。

## 四、方式 C：Docker 容器部署（可选）

```bash
cd deploy
docker compose up -d
# 浏览器访问 http://localhost:8137
```

- 密钥：在 `deploy/.env` 写入 `DEEPSEEK_API_KEY=你的密钥`（compose 自动加载）后 `docker compose up -d`。
- 首次构建需联网拉取镜像与基础依赖。

## 五、故障排查

| 现象 | 原因与解决 |
|---|---|
| 双击 `.bat` 闪退 / 提示"未找到 Python" | 未安装 Python 3.10/3.11/3.12 或未勾选 Add to PATH。按提示安装 3.11 后重试 |
| 提示"Python 3.13 暂不支持" | 离线依赖包仅内置 3.10-3.12 版本，请换装 3.11 |
| 浏览器打开无反应 | 看 `deploy/server.err.log` 与 `deploy/pip_install.log`；端口 8137 被占用时换端口 |
| 语音按钮显示"不可用" | 语音朗读依赖 edge-tts（可选组件），离线环境不可用属正常，不影响核心功能 |
| 提示"服务繁忙，请稍后重试" | 服务异常已自动降级；重启脚本再试 |

## 六、密钥纪律

- 真实密钥只写入 `deploy/.env` 或 `backend/.env`（均已 gitignore，**绝不进仓库**）。
- 仓库仅保留 `deploy/.env.example` 模板（全字段可选）。
- 密钥不会在任何日志或控制台输出中显示。
