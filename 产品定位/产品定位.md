# HealthPick 产品定位

> 版本：v1（2026-08-22）｜状态：产品级定位（对齐"红线是及格线，产品级拿第一"）

## 一、定位一句话

> **「陪伴你吃饭、记得你一切饮食偏好的膳食顾问」** —— 一个"饮食搭子"，不是回答营养问题的机器人。

- **陪你吃饭**：有温度、有陪伴感的对话（一人食陪聊、加班共情、情绪接住）——这是产品魂，直接命中"膳食顾问"赛题场景但不做冷冰冰的顾问。
- **记得你一切**：过敏/禁忌/目标/疾病/饮食台账/坚持天数全部贯穿——"它记得我"是技术底气。
- **膳食顾问**：用户任何营养问题，必须从知识库提取内容回答，来源可溯、数值精确——这是底座，经 168 项自动化回归测试锁定。

## 二、为什么产品化（原始需求的判断）

- **赛题原始需求是功能型**：识别诉求 → 推荐方案 → 回答营养问题——它解决的是"查询"需求，不是"陪伴"需求，**对普通用户并不"痛"**（没有强场景粘性）。
- **及格线 vs 第一名的差距**：比赛规则的硬性需求只是合格分数线（≤59 判定线）；要拿第一，必须把"完成作业"升级为"产品体验"——在"不痛的需求"里做出"让人想再用"的产品。
- **差异化打法**：通用 AI（豆包/ChatGPT）给"正确答案"；我们给"**陪着你吃饭的顾问**"——饮食管理专家（记得你吃了什么）+ 情感陪伴（一个人吃饭也有人陪），这是通用模型替代不了的关系感。

## 三、三模块产品架构（用户档案）

| 模块 | 回答的问题 | 落地 |
|---|---|---|
| **引导** | 你是谁 / 能帮我什么 / 我该从哪开始 | 首屏欢迎语 + 场景卡 + 目标/禁忌/慢病引导（可跳过，对话中随时补录） |
| **记忆** | 它记得我吗 | 用户档案 👤：过敏/禁忌/目标/疾病/台账/坚持天数/近7天，零新表全复用 |
| **陪伴** | 一个人吃饭也有人陪吗 | 一人食/加班/情绪低落/没胃口 四场景，先共情后建议，建议强度分级 |

## 四、核心能力与底线

**三大核心能力**：
1. **陪聊功能**：像真人搭子一样自然（问候简短、共情温暖、闲聊不硬套知识库）
2. **膳食顾问功能**：用户提问必须从知识库提取内容回答——**核心红线（168 项自动化回归锁定）**
3. **工具调用**（愿景）：联网获取实时信息（时令食材/天气/餐厅）——评审期暂缓，作为后续能力写入设计方向

**不能失败的红线**：本地库回答（断网可用）/ 数值精确（只来自速查表）/ 疾病免责 / 用药拒答 / 禁忌排除 / C 库隔离——全部规则硬逻辑 + 168 条自动化用例锁定。

## 五、人群与场景

- 人群：25-45 岁都市白领（减脂塑形 / 增肌强化 / 慢病调理）
- 场景：日常问答、一餐搭建、点单决策（THE LAST 30 SECONDS）、饮食台账、情绪陪伴
