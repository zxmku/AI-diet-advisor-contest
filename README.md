# 10_项目源码_healthpick · AI 智能膳食顾问源码

> 本文档为项目源码目录说明。对外使用请见 `20_交付文档/使用说明.md`（启动方式、真 AI 配置、功能清单与合规红线）。

## 目录分区

| 分区 | 职责 | 说明 |
|---|---|---|
| `frontend/` | 原生 HTML/JS 单页聊天界面（零构建、零依赖） | 含聊天输入、快捷按钮、示例气泡、来源标注、模型徽章、历史会话面板、首屏场景入口卡片、一餐卡 |
| `backend/` | FastAPI 对话编排 + 推荐 + 问答 + 合规层 + 一餐生成 + 饮食台账 + 陪伴 | 8 个 REST 端点、统一响应契约、检索/合成/成本闸门/合规层、`_build_meal` 确定性一餐生成器、`diet_logs` 饮食台账 |
| `knowledge/` | 素材 A/B/C → 结构化 JSON（人工核对后入库） | A 营养基础 16 块 / B 三套方案 14 块 / C 平台服务 15 块 + 禁忌映射 + 同义词 |
| `tests/` | pytest 全量测试 + 红线回归（R1-R8）+ P2/P3/P5 迭代用例 | 环境隔离，不污染线上数据；当前 185 用例全绿 |
| `deploy/` | Dockerfile、docker-compose.yml、.env.example | 容器部署 `cd deploy && docker compose up -d` → http://localhost:8137 |

## 产品能力（P1–P5）

- **P1 首屏人格与场景卡**：欢迎语 + 四张场景卡（减脂/增肌/控糖/今日食谱），点击调 `/api/quick` 渲染真实方案卡；有历史会话自动恢复。
- **P2 过敏追问与记忆**：首次声明过敏以顾问口吻追问细分类型（只问一次），过敏/目标画像持久化进会话，跨轮自动排除禁忌。
- **P3 一餐生成**：说「今晚减脂餐」「给我做晚餐」→ 完整一餐（主蛋白/主食碳水/蔬菜/好脂肪 + 克数 + 总热量 + 营养素 + 做法 + 同族替换），数值仅来自营养速查表 × 份量。
- **P4 一餐卡可视化**：一餐以卡片呈现（总热量大数字、营养素三条、食材清单、做法、替换、来源）。
- **P5 台账与陪伴**：记录/回查饮食台账（`diet_logs` + 速查表估算）；「一个人吃饭好孤单」→ 先共情再轻建议。

## 铁律

1. 素材原件只读：知识库 JSON 由素材加工而来，原件永远不动。
2. 真实 API Key 永不入库：只经环境变量 / `deploy/.env`（已 gitignore）注入，仓库仅保留 `.env.example` 模板。
3. 数值必须工具计算：营养数值（含一餐、台账估算、陪伴建议）一律来自权威速查表，禁止模型推理编造。
4. 意图优先级：用药硬拦截 → 数值精确问答 → 一餐生成 → 检索/LLM/其他；禁忌全链路剔除。

## 快速验证

```bash
pip install -r backend/requirements.txt
cd backend && python -m uvicorn app.main:app --host 127.0.0.1 --port 8137
# 浏览器打开 http://127.0.0.1:8137/
```

自动化红线回归：`python -m pytest tests -q`（185 passed）。含 100 条攻击式指令压力测试（暴风雪）与外部强模型审查，14 项缺陷闭环并回归锁死（暴风雪 8 + 外部审查 6），详见 `30_测试记录/2026-08-22_暴风雪压力测试_摘要版.md`。
