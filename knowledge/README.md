## 加工规则（溯源与零容错）

1. 分块四字段 `{source, chapter, section, content}`；`chapter` 为素材原文标题**逐字保留**（如「第三章常见食材营养数据速查表」）。
2. 正文逐字复制，脚本不改写、不推算任何数值；仅剔除转换噪点行（生成工具水印行、跨页续表标记），噪点行清单写在脚本 `NOISE_LINES`。
3. 文档封面行（标题/版本信息，首个章标题之前）不入库。
4. `disclaimer_type` 标注依据红线 8.5：饮食禁忌/过敏类（海鲜过敏、痛风、麸质、坚果过敏、乳糖不耐受）→ `allergy`；疾病/症状/特殊状态类（肾病、孕期、哺乳期、控压）→ `disease`。
